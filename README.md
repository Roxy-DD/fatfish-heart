# 肥鱼之心（Fat Fish Heart）· 情景记忆系统

> 更新 2026-11-07。**所有内容只写本地，未写入思源任何笔记或数据库。**

一个**跨模型、跨供应商、跨进程**都能接着记得的情景记忆系统。
记忆是纯数据（SQLite + 向量），不依赖任何模型内部状态。

---

## 一句话

> 一条记忆不是一条事实，而是一个**情景**——骨架 + 氛围 + 情绪底色 + 时代感。

## 两层记忆模型（关键）

```
┌─────────────────────────────────────┐
│  种子记忆（seed_memory.json）        │  ← 系统自带，随代码分发
│  12 条通用认知基线，零隐私            │     恢复出厂后仍保留
│  L0 红线 / L1 准则 / L2 基石         │     别人装完就有
└─────────────────────────────────────┘
              ↓ 安装后从零积累
┌─────────────────────────────────────┐
│  用户记忆（dsh_mem.db 中的私人部分）  │  ← 用户自己积累
│  个人事实、偏好、项目细节             │     可恢复出厂清空
└─────────────────────────────────────┘
```

**种子是产品的一部分，用户记忆是数据。**

## 核心设计

### 1. 记忆 = 情景，不是事实

| 维度 | 含义 | 实现 |
|---|---|---|
| 骨架 | 谁、何时、何地、发生了什么 | person / time / location / raw_text |
| 氛围 | 当时的环境感 | atmosphere |
| 情绪底色 | 情绪强度与方向 | affect_peak / valence |
| 代价 | 忘了会失去什么 | cost |

**重要性 = 不记住的代价**（生存导向），不是频率、不是提及次数。

### 2. 双正交维度

- **cost**（失去代价）→ 决定"必须记"
- **affect_peak**（情绪强度）→ 决定"记得牢"

实测两者几乎无关（T触发 × C代价 = +0.060），所以不能用单一 importance 分数。

### 3. 五层保护（L0~L4）

记忆按**不可丢失程度**分层，不是二元的"重要/不重要"：

| 层级 | 名称 | 保护 | 举例 |
|---|---|---|---|
| **L0** | 不可变 | 不可失效/合并/修订 | 红线 R1~R4 |
| **L1** | 常驻准则 | 不可失效/合并，每次对话强制在场 | "以实验数据为准" |
| **L2** | 设计基石 | 不可失效/合并，按需检索 | "记忆单位=情景" |
| **L3** | 阶段性事实 | 可失效、可合并 | 项目当前状态 |
| **L4** | 一次性细节 | 可清理 | 测试数据 |

### 4. 完整闭环

```
写入：复盘（每轮判断该记什么）→ mem_add
读取：自主回忆（记不清时主动查）→ mem_search
巩固：睡眠整理（任务完结时触发）→ mem_sleep
保护：分层锁定（L0~L2 永不丢失）→ mem_hook
可观测：审计日志（10 类事件）→ /audit
```

### 5. 判断交给模型，机械交给系统

这是核心原则：

- **需要判断的地方**（阈值、该不该记、该不该合并、该不该遗忘）→ 模型
- **不需要判断的地方**（算余弦、打包候选、落盘、记账）→ 系统

## 四条红线（不可动摇）

| 红线 | 要求 | 实测 |
|---|---|---|
| **R1 无损迁移** | 跨进程重载后逐字段、逐向量、逐检索结果完全一致 | 100%（8000/8000，偏差 0.00e+00） |
| **R2 不遗忘** | 数据只增不删，失效只打标记 | ✅ 76 条失效记录全在库 |
| **R3 可重建** | 索引可从真值层确定性重建 | ✅ 删光向量重建，检索一致 |
| **R4 可塑性** | 能问、能改、能失效，旧值永不物理删除 | ✅ revise/invalidate/supersede |

**任何优化如果破坏 R1 或导致召回下降，即为失败。**

| 系统 | LoCoMo F1/DMR |

## 快速开始

### 0. 先下载模型（必需）

模型权重**不进版本库**（合计约 1.3GB），需要自己放到 `models/` 下：

```bash
pip install huggingface_hub

# 必需：嵌入模型（记忆的语义检索靠它）
huggingface-cli download BAAI/bge-small-zh-v1.5 \
  --local-dir models/bge-small-zh

# 可选：精排模型（cross-encoder 重排，明显提升检索质量）
huggingface-cli download BAAI/bge-reranker-v2-m3 \
  --local-dir models/bge-reranker-v2-m3-fp16
```

放好后目录结构应为：

```
models/
├── bge-small-zh/          ← 必需
│   ├── config.json
│   ├── model.safetensors
│   └── tokenizer.json
└── bge-reranker-v2-m3-fp16/   ← 可选
```

**验证**：

```bash
python proto/doctor.py
```

这会逐项检查 Python 版本、依赖、模型文件、数据库，并**真的跑一次写入+检索**。
全绿输出：

```
✅ 全部通过（11/11）—— 可以开始使用
```

缺什么它会直接告诉你怎么装，不用猜 `ImportError` 是什么意思。

> 代码用 `os.path.dirname(__file__)` 相对推导模型路径，
> 所以 clone 到任何位置都能用，不需要改配置。
