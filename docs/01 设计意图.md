## 一、推理链条（七步）

**起点不是"造数字生命"，是"模型为什么会忘"。**

### 1. 遗忘来自参数覆盖

梯度下降把所有知识挤进同一组参数，学新的就压旧的。
→ **推论：要不忘，就别共享参数。新东西分配新单元。**

**代码证据**：`MemoryStar` 是独立的向量对象，不与任何权重共享；`memorize()` 遇到低相似度输入直接 `current_galaxy.append(new_star)`，不做任何全局更新。

### 2. 一旦改成分配，唯一的难题是"什么时候算新"

→ 相似度高于阈值且标签相同 = 同一概念，更新代表向量；否则新建一颗星。
→ **整个稳定性-可塑性权衡，被压缩成 `resonance_threshold` 一个数。**

**代码证据**：

```python
# cosmos_net.py RightHemisphere.memorize() Case A
if best_star is not None and best_star.label == y and max_gravity > self.resonance_threshold:
    best_star.vector = CosmosPhysics.merge_matter(best_star.vector, x)
    best_star.mass += 1
# Case B: novelty → new_star
else:
    new_star = MemoryStar(x, y)
    current_galaxy.append(new_star)
```

阈值高 → 倾向新建 → 碎片化；阈值低 → 倾向合并 → 概念混淆。
**这个旋钮的位置是对的：它把两难变成了一个可解释的数**（0.85 ≈ 余弦角 32°）。

### 3. 分配换来的代价是无界增长

→ 必须有离线压缩。于是有"睡眠"：合并近似的、剪掉弱的。

**代码证据**：`dream()` 三个动作——prune / noise / consolidate，全部作用于离线阶段，不与在线学习耦合。

### 4. 压缩到底有没有效，需要一个可算的数

→ 选了质量分布的熵（SE）和「类内散度 / 类间距离」之比（CD）。
→ 这个选择的逻辑是对的：**碎片化 = 熵高；概念混淆 = 类内散度相对类间距离变大。**

**代码证据**：

```python
# analysis.py
SE = -Σ (mass_i/total) · ln(mass_i/total)
CD = mean(类内散度) / mean(类间距离)
```

两个指标正交：SE 只关质量分布，CD 只关向量几何。**指标定义是对的**（计算实现有错，见 `03 缺陷与证据` C 项）。

### 5. 一个估计器不够

→ 拆成「几何/原型」（快、联想）和「统计/分布」（慢、解析），按置信度仲裁。

**代码证据**：`RightHemisphere`（向量引力，快）+ `LeftHemisphere`（均值/方差/z-score，慢）+ `CorpusCallosum`（按 dominance 加权仲裁）。

### 6. 输的一方也要学

**代码注释原话**：`"Inhibit Expression, Not Learning"`

→ 双估计器打架时，只抑制表达，不抑制学习。输的一方仍然更新自己的模型。
→ **这是全仓库最正确的一条**：避免赢者通吃导致专家退化（这在集成方法里是已知问题）。

**代码证据**：`CorpusCallosum.memorize()` 中，仲裁之后无条件执行

```python
self.left_hemisphere.memorize(x, y)
r_msg = self.right_hemisphere.memorize(x, y)
```

### 7. 让遗忘从根上消失的最后一步：把感知器冻住

→ MobileNetV2 只做传感器，`self.model.eval()` + `torch.no_grad()`，不参与训练。
→ 上面那层记忆只做 append，不回头改表征。
→ **表征不漂移，就没有灾难性遗忘。**

**代码证据**：

```python
# retina.py
self.model.eval()              # 推理模式，不更新
with torch.no_grad():          # 无梯度
    features = self.model(img_tensor)
```

**这一步不是修辞。** 它与当前 retrieval-memory / frozen-encoder 路线同向：
把「表征学习」和「记忆增长」解耦，遗忘的根源（梯度覆盖表征）就不存在了。

## 二、七步的关系

```
① 遗忘来自覆盖
      ↓  解法
② 分配而非覆盖  ←─── 判据：相似度阈值
      ↓  代价
③ 无界增长  ←─── 解法：离线压缩（睡眠）
      ↓  怎么知道压缩有效
④ 两个可算的量：SE（碎片）、CD（混淆）
      ↓  单估计器不够
⑤ 双估计器 + 置信度仲裁
      ↓  输的一方会退化
⑥ 抑制表达，不抑制学习
      ↓  表征漂移仍会污染一切
⑦ 冻结感知器，只留可塑记忆
```

**这是一条完整的、可实现的推理链。** 不是七个独立的想法拼起来的。
