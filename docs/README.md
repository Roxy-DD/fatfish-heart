## 我想看实验过程和结论

`docs/` 下 82 份带编号的文档，是逐个实验的复盘（编号 0 到 78）。

**不建议从头读。** 它们是一次实验一份记录，包含大量当时的中间状态。
更好的方式是：

1. 先看 [PROJECT-STATUS.md](PROJECT-STATUS.md) 了解当前结论
2. 对某个结论有疑问，再用文件名里的编号去查对应复盘

编号规律（实测统计）：
- `0-` 到 `30-`：34 份，早期探索（原型阶段）
- `31-` 到 `60-`：30 份，内核成型（存储、检索、迁移）
- `61-` 之后：18 份，红线、容灾、工程化

注意：文档编号（0-78）和实验编号（E-1 到 E-527）**不是一一对应**。
一份文档常覆盖多个实验。

## 文档维护说明

**为什么这么多文档：** 这个项目每条结论都要求有实测数据支撑，
而实验记录本身就是证据。删掉就无法追溯"为什么这么做"。

**新增文档的规矩：**

1. 实验复盘统一用 `编号-主题.md`（编号接着最大的往下排）
2. 面向用户的操作文档用 `大写-主题.md`（如 `OFFSITE.md`）
3. 新增后更新本索引

**哪些文档可能过时：**

编号小的复盘记录的是**当时的结论**，后来可能被推翻。
遇到矛盾时，以 `PROJECT-STATUS.md` 和最新编号的复盘为准。
