## 一、核心突破

**在 RTX 3060 GPU 上，fp16 cross-encoder 精排快 35 倍，且与 LLM 精排融合后命中率达 88.1%。**

| 方案 | 命中率 | 延迟/题 | 244题耗时 |
|---|---|---|---|
| LLM 精排（批量） | 79.1% | ~800ms | ~3.3分钟 |
| cross-encoder int8 CPU | 77.9% | 5712ms | 23分钟 |
| **cross-encoder fp16 GPU** | **78.3%** | **156ms** | **38秒** |
| **融合（LLM ∪ CE）** | **88.1%** | ~956ms | — |

---

## 二、关键发现（踩坑记录）

### 1. int8 在 GPU 上不加速反而慢（1830ms）

int8 量化模型很多算子在 onnxruntime 的 GPU 上不支持，回落 CPU + 频繁 memcpy，GPU 利用率仅 2-19%。

**教训：量化不是越小越快，要看算子支持。fp16 才是 GPU 原生格式。**

### 2. 网络诊断

- 直连 huggingface.co → 超时（被墙）
- 走代理 127.0.0.1:7897 → 能通，但大文件反复断连（ChunkedEncodingError）
- hf-mirror.com → 转 AWS CDN，也连不上
- **唯一有效：走代理 + requests 断点续传**（逐步推进 2MB→838MB→1136MB）

### 3. 环境升级

```
pip install "onnxruntime-gpu[cuda,cudnn]==1.31.1" -i 清华镜像
```
清华镜像 40MB/s，几秒装完（对比 HF 下载几小时）。RTX 3060 = sm_86，Windows wheel 内置支持，驱动 CUDA 13.3 向后兼容。
