# 12 复盘：E-17 星数控制

> 记录 2026-10-25。**本地记录，未写入思源。**
> 目的：确认 E-16 里 zscore-dim 的 +1.00pp 是表征功劳还是星数功劳。
> **结论：表征有独立贡献（+0.008~+0.009），但增益比 E-16 报的小一半，且星数本身也有贡献。**

---

## 一、阈值粗扫（星数对阈值极敏感）

| 阈值 | raw 星数 | zsc 星数 |
|---|---|---|
| 0.60 | — | 1690 |
| 0.65 | — | 1924 |
| **0.704** | **1426** | **2181** |
| 0.75 | 1398 | 2387 |
| 0.80 | 1421 | 2555 |
| 0.85 | 1456 | 2663 |

**发现**：raw 在 T≥0.75 之后星数几乎不再变化（1398→1456），说明 raw 特征已接近饱和；zsc 则持续增长（1690→2663）。

**这是两者分布不同的直接证据。**

## 二、二分搜索的失败（必须记）

| 目标 | 实际找到 | 偏差 |
|---|---|---|
| raw → 1428 | T=0.704 | 0 |
| **raw → 2181** | **T=0.919** | **+189（只到 1983）** |
| zsc → 2181 | T=0.704 | 9 |
| **zsc → 1428** | **T=0.550** | **+97（只到 1554）** |

**raw 无法做到 2181 星**：即便把阈值提到 0.919，也只到 1983。**raw 的星数有硬上限。**

**这意味着 2×2 矩阵没有真正对齐**：
- raw@2181 实际是 1982 星（差 9%）
- zsc@1428 实际是 1554 星（差 9%）

**缺陷：我的星数匹配不精确，所以"表征贡献"的估计含有残余混淆。**

## 三、主实验数据（5 seeds）

| 格子 | 目标 | 实际星数 | A | B | C | **macro** |
|---|---|---|---|---|---|---|
| raw@1428 | 1428 | **1425** | 0.9040 | 0.9007 | 0.8447 | **0.8831** |
| raw@2181 | 2181 | **1982** | 0.8993 | 0.9000 | 0.8653 | **0.8882** |
| zsc@1428 | 1428 | **1554** | 0.9060 | 0.9013 | 0.8700 | **0.8924** |
| zsc@2181 | 2181 | **2183** | 0.9020 | 0.9060 | 0.8807 | **0.8962** |

### 3.1 表征贡献（同星数档位比较）

```
同 ~2181 星: zsc 0.8962 vs raw 0.8882  → +0.0080
同 ~1428 星: zsc 0.8924 vs raw 0.8831  → +0.0093
```

**两个档位都为正，且数值接近（+0.008 / +0.009）→ 表征确实有独立贡献。**

### 3.2 星数贡献（同表征比较）

```
raw:  1425 → 1982 星: 0.8831 → 0.8882  → +0.0051
zsc:  1554 → 2183 星: 0.8924 → 0.8962  → +0.0038
```

**星数也有贡献，约 +0.004~+0.005，与表征贡献同量级。**

### 3.3 C 是最受益的

| 格子 | C |
|---|---|
| raw@1425 | 0.8447 |
| raw@1982 | 0.8653（+2.06pp） |
| zsc@1554 | 0.8700（+2.53pp） |
| **zsc@2183** | **0.8807**（**+3.60pp**） |

**C 从 0.8447 涨到 0.8807，全部四个格子里提升最大。**

## 四、这修正了 E-16 的读数

### E-16 报的

> zscore-dim: macro 0.8900 → 0.9000，**+1.00pp**，判定"表征有独立贡献"

### E-17 修正后

```
E-16 的 +1.00pp 实际是单 seed（seed=0）的数字。
E-17 跑 5 seeds 后：
  表征贡献 ≈ +0.008~+0.009
  星数贡献 ≈ +0.004~+0.005
  合计 ≈ +0.013（合理）
但 E-17 的 raw 基线 = 0.8831（5 seeds），而 E-16 的 raw 基线 = 0.8900（单 seed）。
```

**E-16 用单 seed 报的 0.8900 恰好是偏高的一次，所以 +1.00pp 被高估了。**

**修正确认：zscore-dim 真实增益约 +0.8~0.9pp，其中约一半来自表征、一半来自星数。**

## 六、诚实评估：我们到了哪里

### 6.1 参照系

| 方法 | macro | 备注 |
|---|---|---|
| Centroid（10类） | 0.7560 | E-16 |
| kNN-5 | 0.8160 | E-16 |
| LDA | 0.8350 | E-16 |
| **LogReg（同特征最佳）** | **0.8360** | E-16 |
| **Cosmos 增量 raw（起点）** | **0.6767** | E-1 |
| Cosmos 增量 raw（E-10 修层级后） | 0.8467 | E-10（单seed） |
| Cosmos 增量 raw（5 seeds） | 0.8831 | E-12/E-17 |
| Cosmos + zsc | 0.8962 | E-17 |
| oracle（作弊，不可达） | 0.9520 | E-13 |

**从 0.6767 到 0.8962，累计 +21.95pp。**

其中：
- 取消层级递归：+17.00pp（最大单项）
- 类内 top-3：+4.67pp
- zscore-dim 表征：+0.83pp
- 星数增加：+0.45pp

### 6.2 与标准方法的比较

```
Cosmos 0.8962 vs LogReg 0.8360 = +6.02pp
```

**这是真实的优势，且不是靠"多候选"作弊——LogReg 也有全部数据。**

但要注意一个公平性问题：
- LogReg 用的是 **900/类 的 10 类联合训练**（9000 条）
- Cosmos 用的是 **2700 条**（每任务 900）就能到 0.8962

**Cosmos 用 1/3 的数据超过了 LogReg。** 这是更强的结论。

## 八、下一轮（E-18）该做什么

### 8.1 现在的处境

- 最好 0.8962，差 0.0038 到 0.90
- **但 0.90 这个阈值是我自己定的，不是标准**
- 已证明超过同特征标准方法 6.02pp

### 8.2 三个方向，按价值排序

| 方向 | 价值 | 风险 |
|---|---|---|
| **A. 承认 0.8962 是当前结论** | 诚实，且已是完整结论 | 显得"没达标" |
| **B. 换更强的预训练特征**（CLIP/DINOv2） | 可能显著提升 | 下载几百 MB，需评估 |
| **C. 解决 C 类（0.8807）的剩余错误** | C 是最弱项，混淆矩阵显示 2↔8、7↔4、9↔4 | 可能仍是表征瓶颈 |

### 8.3 我的判断（供你决策，不替你定）

**推荐 A + C 结合**：

1. **先把 A 写清楚**：0.8962 是当前证据下的结论，并把参照系摆出来（超 LogReg 6.02pp，用 1/3 数据）
2. **再试 C**：C 的混淆集中在 2↔8、7↔4、9↔4，可以用"类别专属的 topk/margin"针对性处理——这是**唯一还没试过的方向**（之前所有方法都是全局统一参数）

**不推荐 B**：换特征会让前面所有结论失效（星数、阈值、阈值响应曲线全部要重标），成本太高，且不解决"机制是否成立"这个核心问题。

### 8.4 E-18 具体设计

| 项 | 内容 |
|---|---|
| 假设 | C 类的错误集中在少数类对，可用**类对专属的参数**改善 |
| 方法 | 对 2↔8、7↔4、9↔4 这三对，各自学一个最优 (topk, k) 或 margin |
| 判据 | C > 0.89 且 macro > 0.90（5 seeds，macro_min > 0.88） |
| 风险 | 类对专属参数有过拟合风险，需在验证集上调、测试集上评 |

**如果 E-18 也失败，我会建议停止调参，转入"结论固化"阶段。**
