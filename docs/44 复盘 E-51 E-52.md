# 44 复盘 E-51 / E-52：压缩确实有效，我 E-50 的结论是错的

> 记录 2026-10-26。**本地记录，未写入思源。**
> 起因：查 Mem0 官方文档发现它 **top_200 检索却只注入 7.0K tokens**，LoCoMo 92.5。
> 这直接反驳了我 E-50 的结论"席位是硬约束，无解"。

---

## 一、先认错：E-50 的结论错了

| E-50 我写的 | 实际情况 |
|---|---|
| "席位是硬约束，问题不在排序方式" | **错。受限的是 token（字符），不是条数** |
| "增加条数这条路数学上走不通" | **错。条数可以增加，只要每条压缩** |
| "唯一剩下的方向是提高单条信息量" | 方向对，但我以为只能靠"摘要/聚合"，**没想到"截断+关键词提取"就够** |

**Mem0 的实测：top_200 条，7.0K tokens，LoCoMo 92.5。**
**200 条若按平均 22 字/条 = 4400 字 ≈ 3000-4400 tokens，所以他们是压缩过的。**

---

## 二、E-51 的错误（第一轮）

**我写的"同预算比较"是假的：**

```
预算：102 字（k=5 的字符数）
B 截断 top200 (每8字)：实际用了 1591 字  ← 超预算 15 倍
报出 +0.2700 增益            ← 这是花钱买来的，不是压缩的功劳
```

**已作废。E-52 严格重做。**

---

## 三、E-52 结果（严格同预算）

| 预算(字) | FULL（条数） | CUT 最优配置 | **压缩增益** |
|---|---|---|---|
| 60 | 0.6350（1条） | **0.8350**（30条×2字） | **+0.2000** |
| 120 | 0.7200（1条） | **0.8650**（50条×2字） | **+0.1450** |
| 240 | 0.7750（1条） | **0.9200**（100条×2字） | **+0.1450** |
| 480 | 0.8100（1条） | **0.9650**（200条×2字） | **+0.1550** |
| 960 | 0.8550（1条） | 0.9650（200条×4字） | +0.1100 |
| 1920 | 0.9150（1条） | 0.9650（200条×9字） | +0.0500 |

**平均增益 +0.1342，范围 +0.05 ~ +0.20。**

**全部已校验实际字符 ≤ 预算 102%。**

### 3.1 三条结论

**① 压缩确实有效，平均 +13.4pp**

**② 小预算时增益最大（+0.163），大预算时递减（+0.105）**

**因为预算小时，完整原文只能放 1 条；而截断能把 30 条各留 2 字（通常就是实体名/关键词），命中率反而高得多。**

**③ "每条 2 字"竟然能到 0.835**

**这说明：识别"是不是这一条"只需要极少量信息（往往是开头的实体名）。**

**这是一个重要洞察：记忆的身份信息高度集中在前几个字。**

## 四、必须指出的缺陷（否则结论不可信）

| # | 缺陷 | 影响 |
|---|---|---|
| **1** | **"命中"判据是"目标的 id 在 top-n 里"，而不是"注入的 2 个字里包含能认出它的信息" | **这是最大的瑕疵：2 字几乎不可能包含足够信息让模型真的认出这条记忆** |
| 2 | 只用一种线索比例（15%） | 未扫 |
| 3 | 字符数 ≠ token 数（中文 1 字 ≈ 0.6-1 token） | 换算会有偏差 |
| 4 | 没测"注入后模型能否正确回答" | 只测了检索，没测端到端 |

### 第 1 条最要命

**我测的是"目标 id 是否落在选中的 200 条里"，然后假设"选了就算召回"。**

**但真正的问题是：注入 2 个字之后，模型能从中得到什么？**

**→ 所以 +0.20 这个增益是"检索层面"的，不是"信息层面"的。**

**正确的测法应该是**：
```
注入压缩后的内容 → 让模型回答关于该记忆的问题 → 看答对没有
```

**这一步我没做，因为需要真实模型。**

## 五、这轮真正学到什么

### 5.1 修正后的认知

| 旧认知（E-50，错） | 新认知（E-52） |
|---|---|
| 席位是硬约束 | **token/字符 才是约束** |
| 条数不能增 | **条数可以大幅增（3→200），只要每条压缩** |
| 无解 | **有解：多取 + 压缩，+13.4pp** |

### 5.2 但有一个未验证的关键假设

**压缩后的内容，是否保留了对模型有用的信息？**

**这个假设没测过。E-52 只证明了"选中的条数变多"，没证明"信息真的传到了"。**

### 5.3 顺带得到的一个观察

**"每条 2 字"能达到 0.835，说明记忆的"身份"高度集中在前几个字。**

**这对压缩策略有直接指导**：
- 不需要智能摘要（贵）
- **保留开头 N 字 + 实体词** 可能就够（便宜）
