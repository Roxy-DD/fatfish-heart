# 02 分层判定：哪些是真的

> 建立 2026-10-25。
> **分层依据：内容是否承担 load-bearing（承重）功能，不按文风分层。**
> 判据：把他写的这段文字删掉，机制是否仍然成立。
> 删掉后机制不变 = 装饰；删掉后机制塌掉 = 承重。

---

## 一、三层切分

| 层 | 内容 | 判定 |
|---|---|---|
| **设计层** | 阈值分配 / 质量计数 / 分裂 / 梦境合并 / 双估计器 / 冻结感知器 | ✅ **成体系，是真的** |
| **实现层** | 加噪顺序 / 修剪规则 / 左脑维度 / CD 计算 | ❌ **想法对，代码没跟上** |
| **汇报层** | 莫比乌斯 / 哥德尔 / 辩证统一 / 零遗忘 / Figure 1 / k=0.34 | ❌ **装饰，部分伪造** |

**关键观察**：第三层不包含任何设计。删掉第三层，第一层一条都不少。

换句话说：**哲学外衣与机制之间没有推导关系**。它不是"因为辩证统一所以要用阈值分配"，而是"先做了阈值分配，再给它套一个辩证统一的解释"。

## 三、实现层（想法对，实现错）

**这一层最值得留：保留想法，修掉实现。**

| # | 真实想法 | 代码实际做的 | 该改成 |
|---|---|---|---|
| **A** | 退火/噪声可以跳出局部最优 | **先加噪、再按固定阈值合并**。σ=0.05 就把余弦从 0.996 打到 0.34，合并彻底无法发生 | 噪声应作用在**阈值**上（随机化 T ± δ），或在合并**之后**扰动 |
| **B** | 弱记忆该被遗忘 | `if start_count > 50: keep mass > 1`。mass==1 = 只见过一次 = **刚学的** | 遗忘按「新鲜度 + 质量」双阈值，不能把"新"和"弱"混淆 |
| **C** | 类内散度 / 类间距离能测混淆 | 分母用簇心欧氏距离，在归一化向量上接近常数（≈√2），CD 被压到 0.15 量级 | 用**角度距离**，或在原像素空间算 |
| **D** | 双脑动态平衡 | 左脑 `is_pixel_data = (len==784)`；Retina 输出 1280 → 左脑永久返回 `(None, 0.0)` | 维度判断改为 `len in (784, 1280)`，并分别建几何特征 |
| **E** | 合并相似概念 | `if star.label == kept_star.label` 才合并 → 永远发现不了"两个标签其实是同一件事" | 无监督合并应允许跨标签，或加"标签冗余检测" |
| **F** | 层级会自动涌现 | 分裂逻辑存在，但 `dream()` 不递归到 children，子星池只增不压 | 合并需递归 |

**A–F 的判据（可直接用于验收）**：

| 编号 | 验收判据 |
|---|---|
| A | 加噪后，合并数应 ≥ 不加噪时的合并数 |
| B | 持续学习 3 个任务后，任务 1 的召回率应 > 90% |
| C | CD 在原像素空间与角度空间应量级一致（同一批数据差 < 2 倍） |
| D | 左脑在 1280 维输入下应有非空 `knowledge_base`，dominance 应出现双向变化 |
| E | 构造两组"同义标签"，合并后应检测到冗余 |
| F | 做梦后，根星数与总星数（含子星）都应下降 |

## 五、判定一句话

> **删掉全部第三层，剩下的是一套正确方向、残缺实现的 ART 系增量记忆原型。**
>
> **第三层不是"写得夸张"，是"替换了证据"。** 前两类是文风问题，第三类不是：
> - Figure 1 声称是实验结果，实际是两行公式
> - k=0.34 声称是推导，实际是用错误分母回拟合
> - "已验证"声称有数据，实际没有
>
> **这三条的性质是"汇报失真"，不是"修辞夸张"。** 区别在于：夸张容易被读者打折，伪造不会。

## 六、为什么必须分清这两种

因为处理方式不同：

| 类型 | 处理 |
|---|---|
| 文风夸张 | 改文字即可，机制不动 |
| **汇报失真** | **必须删掉或替换成真数据**，否则整份文档可信度归零 |

**一个伪造的图，会让十个真实的判断一起被怀疑。** 这是 README 当前最大的实际损失——不是"吹牛"，是把真东西埋了。
