# 51 原型 v0.2 记录：情景记忆库能跑了

> 记录 2026-10-26。**本地记录，未写入思源。**
> 位置：`proto/cosmos_mem/`
> 状态：**能跑，可迁移，可塑，但有几处明显粗糙**

---

## 一、做了什么（按用户定义）

| 用户定义 | 实现 |
|---|---|
| **一条记忆 = 一个情景** | `Episode` 含：四要素 + 骨架 + 氛围 + 情绪 + 原文（不切碎） |
| **四要素切分** | 抽 人/时间/地点/话题（HingeMem 规则） |
| **情绪二维** | valence（效价 −1~1）+ arousal（唤醒 0~1），非 27 类 |
| **情绪采集** | 显式标记 > 规则 > 关键词，三级 |
| **可塑性** | `revise`（改）、`invalidate`（失效不删）、`supersede`（新取代旧） |
| **不遗忘** | 原文永久保留，失效只打标记 |
| **无损迁移** | `migrate` 单文件复制，条数校验一致 |

---

## 二、实测通过的

| 功能 | 结果 |
|---|---|
| 写入带情绪识别 | ✅ "千万别搞错…出大事" → 效价 **−1.00** |
| 显式标记 | ✅ "记住：密码8848" → 重要度 **0.90** |
| **查"我电脑密码" → score 2.225，排第一** | ✅（修复前查不到） |
| 修订 | ✅ 第 2 版，原文更新，revision 递增 |
| 失效+取代 | ✅ 旧值标失效、仍可查；新值优先 |
| 溯源 | ✅ 显示"被 xxx 取代" |
| **迁移** | ✅ 条数一致，查询结果相同 |

## 三、修掉的三个真实缺陷（都是实跑发现的）

| # | 缺陷 | 修法 |
|---|---|---|
| **1** | **"我电脑密码"查不到"我电脑的登录密码是8848"** | FTS5 整串 MATCH 失败 → 改成 **查询拆 2-gram + OR + 子串兜底** |
| **2** | **"在会议室"被当成人名** | 先剥离地点/时间短语再抽人 |
| **3** | **平静但重要的内容情绪全 0** | 加入 `importance` 字段（密码/约定/亲情等），独立于情绪 |

**第 1 条最严重**——它说明**纯 FTS5 对中文短查询不可靠**，必须配子串兜底。

---

## 四、仍然粗糙的地方（诚实清单）

| # | 问题 | 影响 |
|---|---|---|
| **1** | **人名抽取靠正则**，会漏会错（早期把"老王讨"、"最终确"当人名） | 真实使用会大量出错 |
| **2** | **没有真正的语义检索**（用 FTS + 结构化 + 规则，没接 BGE） | 同义改写查不到 |
| **3** | **情绪靠关键词表**，覆盖极有限 | 大量情绪识别不到 |
| **4** | **"氛围"要手工填**，没自动抽取 | 用户不会填 |
| **5** | **没做链式展开**（夕阳→小时候的夕阳→小时候的事） | 用户最看重的触发机制没实现 |
| **6** | 四要素的"话题"只有 5 个粗类 | 粒度太粗 |
| 7 | 没有索引重建/版本校验 | 生产还需要 |

## 六、怎么用（给用户）

```bash
cd proto/cosmos_mem

# 写入（--explicit 表示"这条记住"）
python cli2.py add "7月15日，老板说这个项目千万别搞错" 
python cli2.py add "我电脑密码是8848" --explicit

# 询问
python cli2.py ask "我电脑密码"
python cli2.py ask "老板强调过什么" --top 3

# 改记忆（可塑性）
python cli2.py revise <ep_id> --text "修正后的内容"

# 标记失效（旧值不再主动出现，但仍可查）
python cli2.py invalidate <ep_id> --by "新的正确内容"
python cli2.py ask "参数" --all      # --all 才看到失效的

# 查看/统计/迁移
python cli2.py list --n 20
python cli2.py stats
python cli2.py migrate new.db
```

## 七、一句话

> **v0.2 能跑了：情景结构、二维情绪、可塑性、无损迁移都已实现并通过实测。**
>
> **但它是"规则驱动"的，不是"语义驱动"的——人名靠正则、情绪靠词表、检索没接 BGE。**
> **所以现在只能做 demo，不能面对真实文本。**
>
> **P0 是接语义检索 + 做链式展开（后者是用户最看重的"夕阳触发"机制，目前完全没做）。**
