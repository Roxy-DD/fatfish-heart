## 三、无效的改动（全部失败）

| 方法 | 结果 | 失败原因 |
|---|---|---|
| `margin`（E-14） | 三档完全相同 | **空操作**：条件恒真 |
| `zc`/`zmax`（E-14） | 崩到 0.016 | **除以 sd 奖励窄分布类** |
| `rank`（E-15） | 崩到 0.106 | **取最大值百分位恒为 1.0** |
| `margin2`（E-15） | −12% ~ −25% | tk/mx 不一致里多数是 tk 对 |
| `tk_cal`（E-15） | 单调变差 | 类内均值差是真实信号，不是偏置 |
| `prior_norm` 大 beta | B 掉到 0.057 | 惩罚大类摧毁大类 |
| `evt_beta` | 崩到 0.48 | 校正项 0.9 >> 信号 0.05 |
| `density` | 归零 | alpha 量级错（应 ~0.01） |
| `centroid` | −10pp | 丢失类内分布 |
| **`per-class 调参`（E-18）** | **验证 +1.56pp，测试 −0.11pp** | **过拟合** |

**11 轮里，只有 3 个改动真实有效。其余 10 个全失败。**

## 四、三个被推翻的假设（包括我自己的）

### 4.1 「子星是冗余复制品」（我的猜测，E-10 后）

**被 E-11 否证**：

| 组 | macro(top3) | 增益 |
|---|---|---|
| root only (411) | 0.7533 | — |
| + 随机复制 (1428) | 0.8067 | +5.34pp |
| **+ 真实子星 (1428)** | **0.8900** | **+13.67pp** |
| + 噪声扰动 (1428) | 0.7533 | +0.00pp |

真实子星比随机复制多 **8.33pp** → 子星携带真实类内变异。

### 4.2 「C 的困难来自类间混淆（内在难度）」（E-12 复盘）

**被 E-13 否证**：C 的 oracle = 0.9413，与 A/B 相当。C 的短板是**在 10 个标签里选对**，不是**在 6/7/8/9 里选对**。

### 4.3 「6.89pp 干扰是可回收的」（E-13 核心解释）

**被 E-16 否证，这是最重要的纠正**：

```
10 类全选，LogReg（同特征）      = 0.8360
10 类全选，Cosmos 联合训练        = 0.8350
Cosmos 增量（10 类全选）          = 0.8831   ← 超过所有标准方法
Cosmos oracle（3-4 类里选）       = 0.9520   ← 作弊上限
```

**oracle 的 0.9520 不是"特征容量"，是"候选数从 10 减到 3–4"带来的。**
**它测的是"题目变简单"，不是"可回收损失"。**

**我用一个不可达的上限当目标，追了 E-14/E-15 两轮。** 这是本次迭代最大的方法论失误。

## 六、E-18 的失败（最重要的一次负面结果）

| 项 | 值 |
|---|---|
| 调参方式 | 验证集（seed=0）贪心搜索，81 次试参 |
| 验证集增益 | **+1.56pp**（0.8844 → 0.9000） |
| **测试集增益** | **−0.11pp**（0.8781 → 0.8769） |
| 改动类别数 | 4/10（`0:5, 1:1, 5:8, 7:5`） |
| 判定 | **过拟合** |

**验证集看到 +1.56pp、测试集却是 −0.11pp。**

这证明：**类别专属参数在这个数据规模上不可行**。81 次试参、10 个类、300 测试样本 → 搜索空间大于数据支撑能力。

**这是"参数调优已到边界"的直接证据。**

## 七、最终结论（证据支撑）

### 7.1 机制层面

| 主张 | 判定 | 证据 |
|---|---|---|
| 冻结感知器可行 | ✅ | MobileNetV2 312/312 层载入，跨进程一致 |
| 分配而非覆盖 | ✅ | 旧星向量未被改写 |
| **质量计数→分裂（子星）** | ✅ **但层级有害** | E-10/E-11：子星 +13.67pp，层级 −17pp |
| 质量加权合并 | ✅ | 结构验证 |
| SE/CD 正交诊断 | ✅（修 C 后） | 量级合理 |
| 抑制表达不抑制学习 | ✅ 机制存在 / ❌ 无价值 | dominance 是吸收态 |
| 单一阈值管分配+合并 | ❌ | E-7：两件事需两个阈值 |
| **跨进程迁移** | ✅ **100%** | E-4：8000/8000，偏差 0.0 |

### 7.2 性能层面

> **Cosmos 增量 topk3 = 0.8831（seeds 0–4），
> 同特征最佳标准方法 LogReg = 0.8360（用 3.3 倍数据）。
> 净优势 +6.02pp，且只用了 1/3 训练数据。**

- **不使用 oracle**（作弊），不合并候选集
- **不使用 10 类联合训练**，是真正的增量
- 判据 `macro > 0.90` **未达成**（最好 0.8962，诚实口径 0.8781）

### 7.3 剩余瓶颈

混淆矩阵（E-16）：总错误 99 条，**分散在 41 个类对**，前 10 类对占 47.5%。

**错误不是集中在少数类对，所以"类对专属参数"（E-18）注定过拟合——已实测证实。**

最难：2（0.758）、8（0.797）；最易：0（0.990）、4（0.963）。

## 九、我的建议（不替你决定）

### 9.1 停止调参

**理由**：11 轮里 10 个方法失败，最后一轮（E-18）过拟合。**继续在同一特征上调参，期望收益已经很低。**

### 9.2 三条路，按性价比

| 路线 | 说明 | 成本 | 预期 |
|---|---|---|---|
| **A. 固化结论** | 把 0.8831（超 LogReg 6.02pp）写成模型手册，边界写清 | 低 | 确定产出 |
| **B. 换特征** | CLIP/DINOv2，或与任务匹配的编码器 | 中（下载+重标定全部阈值） | 可能 +2~5pp |
| **C. 换任务** | 用更难的细粒度数据集检验机制是否仍成立 | 中 | 检验普适性 |

**我倾向 A → C → B**：先固化（确定产出），再验普适（C 能证伪机制），最后才为刷分换特征（B）。

## 十、一句话

> **11 轮迭代，3 个改动真实有效，10 个失败，1 次过拟合，8 类方法论错误（其中 4 类本可避免）。**
>
> **最大单项收益来自"拆掉层级"（+17pp）——不是加机制，是减机制。**
>
> **最大教训是"用作弊上限当目标"（浪费两轮），以及"参数调优到边界后必须停"。**
>
> **最终：0.8831，超同特征最佳标准法 6.02pp，用 1/3 数据。判据 0.90 未达成，且我建议不再追。**
