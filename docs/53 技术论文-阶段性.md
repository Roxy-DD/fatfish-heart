## 摘要

本项目试图解决一个具体问题：**让模型换供应商、换规格、换进程之后，仍能"接着记得"。**
核心主张是**记忆与模型解耦**——记忆是纯数据，不绑任何模型、代码或进程。

经过约 85 轮实验（E-1 ~ E-85），我们确立了四件不可妥协的底线，并在其上实现了多个可验证的突破：

1. **无损迁移 100%**（跨进程逐字段、逐向量、逐检索结果完全一致，偏差 0.00e+00）
2. **不遗忘**（数据只增不删，失效只打标记；准确率随数据量单调上升）
3. **索引可确定性重建**（索引是派生结构，删掉可从真值层无损重算）
4. **可塑性**（记忆能问、能改、能被取代，但旧值永不物理删除）

在此之上，性能被优化约 **5 倍**（端到端 21.2ms → 4.2ms），存储压缩约 **4.5 倍**（195MB → 43MB）。

最重要的**方向性结论**来自一组判决性实验：**遗忘是"入口收缩"而非"存储消失"**（Availability 100% / Accessibility 40%）；以及**模型本身有能力判断自己是否真的记住了**（自检 F1 = 0.974），且这种能力显著强于任何手写规则。

最终设计收敛为：**让记忆系统由模型自己操纵和迭代**，而不是由人预先规定它如何组织、如何遗忘、如何加权。

## 第 1 章 项目进展与结果

### 1.1 已实现并已验证的能力

#### 1.1.1 四件不可妥协的底线（所有实验的硬约束）

| 编号 | 底线 | 实测证据 | 破坏判据 |
|---|---|---|---|
| **R1** | **无损迁移 100%** | 8000/8000 = 100%，余弦偏差 0.0（E-4）；10万条 int8 迁移后偏差 0.00e+00（E-42/E-43） | 迁移后任何一条、一个向量、一次检索结果不一致 |
| **R2** | **不遗忘** | 1k→32k 样本，准确率 0.904→0.964 单调上升（E-29）；失效只打标记不删除（E-63） | 因优化导致准确率下降或旧数据丢失 |
| **R3** | **索引可确定性重建** | 相同真值层+相同种子，两次建索引结果完全一致（E-44）；删光向量表重建后检索一致（E-63/E-68） | 索引重建结果不可复现 |
| **R4** | **可塑性** | revise / invalidate / supersede 全部工作，旧值可溯源（原型 v0.2~v1.3） | 覆盖式更新改写旧记忆 |

**这四条是所有后续工作的"红线"。任何实验，只要破坏其中一条，即判为失败，不计入进展。**

#### 1.1.2 记忆与模型解耦（I-1，最初目标）

记忆以**纯数据**形式存储：
- 原文（永久保留，为换 embedding 重算留底）
- int8 量化向量 + 量化参数（lo/scale）
- 结构化字段（四要素、情绪、能力范围等）
- schema 版本号（`cosmos-mem/1.x`）

**关键验证**：量化后重载，最大偏差 0.00e+00。原因是量化是确定性映射，同样的 int8 值和参数，反量化必然得到同一个 float32 向量。**量化不破坏无损迁移。**

#### 1.1.3 三路检索 + 路由

| 查询类型 | 冠军 | 分数 | 出处 |
|---|---|---|---|
| 单跳事实 | 任一路 | 1.000 | E-39 |
| **多跳关系** | **图遍历** | **1.000**（向量仅 0.53） | E-39 |
| **语义模糊** | **向量** | **0.570**（关键词/图均 0） | E-39 |
| 精确标识 | 关键词 | 1.000 | E-39 |
| **三路组合路由** | — | **0.881** | E-39 |

**关键发现**：没有单一检索器能覆盖所有查询类型；但**无脑加权融合会伤害两跳查询**（逐条比对：融合胜 0 / 平 129 / 负 5，全部负在 Q2 两跳）。正确做法是按查询类型路由，而非 RRF 加权平均。

#### 1.1.4 性能优化（累计约 5 倍）

| 项 | 最初 | 现在 | 提升 | 出处 |
|---|---|---|---|---|
| V 检索（73k 条） | 4.33 ms | **0.096 ms** | **45×**（HNSW） | E-44 |
| K 检索（10万条） | 5.84 ms | **0.044 ms** | **132×**（FTS5） | E-44 |
| 存储（10万条） | 195 MB | **43 MB** | **4.5×**（int8） | E-41 |
| 编码（单条） | 8.16 ms | **4.06 ms** | **2.0×**（ONNX） | E-45 |
| **端到端** | **21.2 ms** | **≈ 4.2 ms** | **5.0×** | 累计 |

**必须记录的正确认知修正**：int8 只有**存储收益**（195→43MB），**没有速度收益**（实测 1.00×，甚至原生整数运算慢 17×）。之前"int8 能加速"的判断是错的。

#### 1.1.5 写入完整性闸（7 类缺陷检测）

| 轮次 | 规则来源 | 覆盖 | 误伤 | F1 |
|---|---|---|---|---|
| E-73 | 我原来的 3 类 | 1/18 | 0 | — |
| E-74 | +模型发现的 4 类 | 13/18 | 0 | 0.839 |
| E-75 | 按模型标准收紧 | 16/18 | **0** | **0.941** |

**7 类缺陷**：裸代词、无锚时间、纯情绪、missing_object（有谓词无对象）、vague_value（有数值槽无数字）、undefined_convention（用未定义的约定）、vague_summary（长而空）。

**这 4 类新缺陷是模型自己发现的**，不是我预设的——这本身就是"模型能自我迭代"的直接证据。

#### 1.1.6 能力范围矩阵（替代"完整度"标签）

**关键突破**：记忆不该标"完整/不完整"，该标"能回答哪类问题"。

六个维度：`existence`（有没有发生过）/ `identity`（是谁）/ `time_exact`（具体哪一天）/ `time_range`（大概什么时候）/ `value`（具体数值）/ `location`（具体地点）。

**验证**：事件性记忆"爷爷去世了"→ existence=✓ / time_exact=·，**这是对的**，不是缺陷。检索按问题维度路由，13/13 一致率（E-78）。

这直接源自用户的关键洞察：**"事件性记忆没有具体时间锚点，而是关于'有没有发生过'的事。"**

#### 1.1.7 模型的自我判断能力（E-69 判决性验证）

**核心结论：模型自己知道它有没有正常回忆。**

| 指标 | 值 |
|---|---|
| 自检 F1 | **0.974** |
| 精确率 | **1.000**（零误判） |
| 召回 | 0.950 |

**对比**：模型的判断能力（F1 0.974）显著强于我的记忆系统的检索能力。

**→ 用户判断成立："模型自己具有这种能力，但是它的记忆系统可能会限制它的能力。"**

### 1.3 identity 维度的完整突破（E-85 → E-91，补充记录）

**这是组装阶段（E-86 之后）完成的第一个完整突破，单独记录。**

| 版本 | 精确率 | 召回 | F1 | 方法 |
|---|---|---|---|---|
| E-85 纯规则 | 1.0000 | 0.8000 | 0.8889 | 姓氏白名单 + 称呼正则 + 关系槽 |

**关键发现**：
1. jieba 的 nr（人名）标签能补上规则漏报的"全名"（陈默、王雅琴）

**最终结论：identity 维度已不是瓶颈。** 规则（精确）+ jieba nr（补召回）+ 精确的词表边界，三者组合达到 44 条全对。

### 2.2 关键判决性实验数据

#### 2.2.1 遗忘是"入口收缩"（E-47）

| 指标 | 数值 |
|---|---|
| Availability（数据还在） | **100%** |
| Accessibility（线索只剩 5%） | **40%** |

**结论**：数据全在但查不到 → 入口收缩，不是存储消失。这支持用户的"聚光灯"模型，且有文献佐证（静默印迹 silent engram，Tonegawa 2017）。

#### 2.2.2 代价 ≠ 当下情绪，而 ≈ 失去情绪（E-61）

| 关系 | Pearson |
|---|---|
| 代价 × 当下情绪 | +0.258 |
| **代价 × 失去情绪** | **+0.671** |

**结论**：代价本质上是一种情绪，只是藏在"失去"里，被习惯化掩盖了。这直接支持用户的判断"习以为常的东西，人们感觉不到它其实是情绪主导的"。

#### 2.2.3 创伤是"情景触发"而非"常驻回忆"（E-62）

| 组 | 平时存在感 | 触发强度 |
|---|---|---|
| 创伤 | **2.83** | **6.83** |

**结论**：创伤是"平时低存在感 + 高触发"，不是杞人忧天式常驻。用户对创伤的定义正确。

#### 2.2.4 模型自检能力（E-69）

F1 = 0.974，零误判。模型能可靠判断"这条记忆能不能回答问题"，且强于任何手写规则。

#### 2.2.5 模型能自己发现缺陷类型（E-73）

模型从 21 条语料中**自己归纳出 4 类我没想到的缺陷**：missing_object、vague_value、undefined_convention、vague_summary。这 4 类落成规则后，覆盖率从 1/18 提升到 16/18。

### 2.4 实验方法记录（用户的方法论）

#### 2.4.1 三步法

```
1. 抽象类比  把技术问题 → 抽象成现实生活中的具体问题
2. 搜索规律  去各行各业搜大家怎么解决，了解真实现象、规律、数据
3. 迁移套用  从这些信息里发现规律，迁移到当前问题
```

#### 2.4.2 核心逻辑

> "规律只在一个地方出现，就是现实生活。别的各行各业，都只是通过各自的视角，去记录他们所看到的东西。"

**推论**：单一学科结论是某个视角的投影，不是规律本身；多行业交叉印证才接近规律。

#### 2.4.3 不预设门槛

> "这种实验的东西不应该预设门槛，而是遇到了什么问题，看什么会造成效果变差或者变好，然后不断地去确定边界，不断地完善修改就行了。"

**翻译**：不写"必须 >0.90"，改写成"什么让它变好？什么让它变差？边界在哪？"

#### 2.4.4 逻辑是拟合，不是真理

> "在现实世界里，逻辑不可靠，只有现实规律才是绝对的真实……你任何的逻辑规律之类的东西，其实都是拟合出现实规律后的一种逻辑惯性，它不一定就是正确的。"

**操作含义**：数据获取途径本身可能错 → 换途径验证；任何常数都不能冻结 → 阈值由当前数据实时决定。

#### 2.4.5 文献只是借势，不是权威（最高优先级）

三层优先级：
```
1. 我自己跑出来的结果        ← 最高
2. 现实世界能观察到的现象    ← 高
3. 行业/文献/权威的结论      ← 最低（只是借势）
```

**具体规则**：搜到规律只当"候选假设"；文献说 A 好，必须自己跑一遍验证；若我的结果与文献冲突，信我的结果。

#### 2.4.6 实验是获得真理的唯一正确途径（用户最新强调）

> "不断地实验，不断地去测，得到新的方法。实验是获得真理的唯一正确途径。因为思路也只是经验的总结，只有实验出来的结果才能算真相。"

---

### 2.5 用户对实验的要求与指导思想

以下是用户在不同阶段给出的、直接指导实验方向的思想：

1. **记忆与模型解耦**：换供应商、换规格、换进程后还能接着记得，不让模型消失。
2. **情绪是记忆的编号/UUID**：回忆先到情绪，再到内容。
3. **重要以情绪为索引**：恐惧（搞砸丢饭碗）、美好（喜悦幸福）。
4. **遗忘机制不一定适用于 AI**：目的是"知道哪些是重点、哪些不能忘"，而非百分百正确。
5. **反复记忆反而陌生**：深刻不看短期重复频率，看长周期是否一直在重复；生理反应（惊恐、创伤）让人记忆深刻。
6. **记忆是情景，不是事实**：动态场景、氛围、情绪、大环境、时代精神（尼采）。
7. **重要性是生存导向的**：根据物理现实经验判断什么会导致死亡/无法解决问题/活不下去。
8. **记忆是可塑的**：不断询问、能更改的学习型模式，不是静态的固定锚点。
9. **触发 = 情景相似 或 情绪共振**，然后链式展开（夕阳→小时候的夕阳→小时候的事）。
10. **创伤是情景式的**：平时不占位置，遇到相似情景才被唤醒，不是天天在脑子里。
11. **代价是"失去时的情绪"**：习以为常的东西，感觉不到它其实是情绪主导的。
12. **事件性记忆**：没有具体时间锚点，而是关于"有没有发生过"的事；时间可被模糊成范围。
13. **模型自己操纵和迭代记忆系统**：让模型自己实验一遍、自己改，直到它觉得真的记住了。不是由人规定它如何迭代。
14. **底线不可变，在此基础上不断延伸**：迁移百分百，尽量不让能力下降。

## 第 3 章 当前架构总结

### 3.1 存储层（真值层，不可丢）

```
SQLite 单文件（WAL）
├─ episodes      原始记忆 + 结构化字段 + 能力范围 + 情绪 + 代价
├─ vectors       int8 量化向量 + 量化参数
├─ ep_fts        FTS5 全文索引
└─ meta          schema 版本
```

### 3.2 索引层（派生，可重建）

- FTS5 倒排（关键词检索）
- HNSW 图（语义检索，faiss）
- 四要素索引（人/时间/地点/话题）

### 3.3 计算层（可丢弃缓存）

- BGE 向量矩阵（内存，可重建）
- 编码缓存（内容 hash）

### 3.4 能力层（新增）

- **能力范围矩阵**：每条记忆标注"能回答哪类问题"（6 维度）
- **完整性闸**：写入时检测 7 类缺陷
- **模型自检**：判断"这条记忆能不能回答问题"（F1 0.974）

### 3.5 检索路由

```
问题 → 识别问的维度 → 按能力范围筛选 → 三路检索 → 链式展开
     → 该答的答，不该答的老实说"记不清"
```

## 结论

本项目在"不遗忘 + 可迁移"这一硬约束下，完成了一条从"能不能无损迁移"到"记忆系统该如何自迭代"的完整探索路径。

**最重要的三个结论**：

1. **无损迁移是可实现的，且量化不破坏它**（偏差 0.00e+00）。
2. **遗忘是入口收缩，不是存储消失**（Availability 100% / Accessibility 40%）。
3. **模型自己能判断"记住了没有"**（F1 0.974），且这种能力显著强于手写规则——因此记忆系统的正确形态是**让模型自己操纵和迭代**，而不是由人预先规定。

**当前阶段尚未完成的事**：组装进 DSH、真实会话端到端评测、身份/情绪的模型精筛层、链式展开的大规模验证。

**下一步方向**（已明确）：把能力范围做成"规则粗筛 + 模型精筛"两级结构；把自检闭环真正接入写入流程；最终组装为 DSH 可用的记忆层。
