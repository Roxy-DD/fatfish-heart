## 二、物理化计算：文献证实的部分

### 2.1 模拟电路确实一次算完

来源：[UCSB 忆阻器 VMM](https://web.ece.ucsb.edu/~strukov/papers/2020/tnanobounds2020.pdf)、[Nature/PMC AIMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12779548/)

> 「乘法按欧姆定律 `I = GV`，累加按基尔霍夫电流定律 `I_j = Σ G_ij V_i`。
> **整个矩阵向量乘在 O(1) 一步完成**，而数字处理器是 O(N²)。」

**这正是你说的"一下子就能得到结果"。**

### 2.2 电容式方案确实存在，且优于忆阻器

来源：[Towards Capacitive In-Memory-computing (arXiv 2508.13225)](https://arxiv.org/pdf/2508.13225)

> 「电容式记忆：**静态功耗为零**，天生免疫 sneak-path，无需选择器，
> 且与 3D BEOL 集成兼容。」

**你猜"电容"而不是电阻，这个方向在 2025 年的综述里是被专门论证过的。**

### 2.3 电荷泄漏在硬件里是真实存在的

来源：同上 UCSB 论文

> 「加速保持测试（85°C / 15 小时）：电导平均变化 **< 0.8%**，标准差 < 2.7%。
> 这种漂移可以安全忽略，只需**每 6 个月重新调谐一次**。」

**→ 现实中的漂移很慢，不是"快速自然遗忘"，而是"半年才需校准"。**

## 三、动力学实测：纯衰减能不能智能遗忘

我跑了四种规则（[e30_physical_decay.json](C:\Users\xuee\Desktop\肥鱼之心\proto\results\e30_physical_decay.json)）。

### 规则 A：纯指数衰减 + 绝对阈值 → **整体归零**

```
所有条目同一曲线 s(t) = s0·exp(-t/tau)
→ 全部同时越过阈值，一起消失
```

**没有"部分遗忘"，只有"全体遗忘"。**

**→ 物理漏电产生不了"有选择的遗忘"。**

### 规则 B：纯指数衰减 + 相对阈值 → **完全无效**

```
排名相关性（时间推进）: [1.0, 1.0, 1.0, ..., 1.0]
top10% 集合最后是否完全不变: True
```

**指数衰减对所有条目同比缩放，所以排名永远不变。**

**→ 如果判据是"取最像的 k 个"（相对），衰减等于没发生。**

### 规则 C：衰减 + 使用加固 → **自然分层（这才有效）**

```
t=0    均值 0.62  最大 1.6   >0.1 的条数 1000
t=2000 均值 0.19  最大 20.0  >0.1 的条数 73
最终 top10% 占总强度: 0.9986
```

**热门记忆被推到上限（20.0），冷门沉到 0。**

**→ 这是"漏电 + 相互作用"合起来的效果。只有漏电不行。**

### 规则 D：衰减 + 选择性巩固 → **真正实现了"提存"**

```
快组件（会衰减）: 0.65 → 0.03   （几乎归零）
慢组件（不衰减）: 0.00 → 0.19   （持续积累）
已巩固条目: 276 → 307
最终巩固部分占总强度: 88.6%
```

**被巩固的记忆转入不衰减的慢组件，永久保存；未巩固的随快组件消失。**

**→ 这才是"遗忘 + 提存"的正确结构。**

## 四、所以，你的假设要这样修正

### 4.1 你对的部分

| 你的判断 | 现实 |
|---|---|
| 算法是逐步算的，慢 | ✅ 数字 O(N²) vs 模拟 O(1) |
| 物理实体能瞬间出结果 | ✅ 基尔霍夫定律 |
| 记忆和索引可以物理化 | ✅ 电容式 CIM 正在被研究 |
| 不该用算法硬规定遗忘 | ✅ **应该让物理规律来做** |
| 电容之间要有相互作用 | ✅ **这是关键，不能只有漏电** |

### 4.2 你要修正的部分

**❌ "只靠自然损耗就能实现遗忘"不成立。**

**原因很清楚**：

1. **漏电是"无差别的"**——所有电容按同一比例衰减，**相对关系一点不变**
2. **所以要么全忘（绝对阈值），要么等于没忘（相对阈值）**
3. **真正的选择性，必须来自"相互作用"**：
   - **被读取 → 充电**（使用加固）
   - **超过阈值 → 转入不衰减区**（巩固）

**换句话说**：

> **物理提供的是"时间常数"和"同步性"，**
> **不提供"什么该留、什么该走"的判断。**
> **后者必须由"相互作用"（读取、巩固）产生。**

**这恰恰印证了你说的"电容之间的相互作用"——你这句话是对的，而且是整个方案的命门。**

## 五、这个结构在生物学里有对应

来源：[PNAS 突触权重的记忆巩固](https://www.pnas.org/doi/10.1073/pnas.2406010121)、[Cascade Models (Fusi et al.)](https://doi.org/10.1016/j.neuron.2005.02.001)、[tag & capture 模型](https://www.biorxiv.org/content/10.1101/613265v1.full-text)

**生物的做法就是"快衰减 + 选择性巩固"两极：**

> 「**快组件**被动衰减（约 42 分钟时间常数），
> 但**当它超过权重阈值、且后突触电压超过阈值时，衰减的部分被转入不衰减的慢组件**。
> 非信息性的变化自然衰减消失，信息性的被固化。」

**而且"级联模型"（Fusi）指出**：多个时间常数的级联，能把记忆寿命延长到远超单个组件——**这正是硬件可以并行实现的**。

## 六、如果真要做硬件，结构应该是

```
一层快电容（会漏电，时间常数分钟级）
        ↓ 读出时充电 / 超过阈值时触发
一层慢电容（不漏电，永久）
        ↓
读出：两层的加权和
```

**三条设计原则（从实测推出）：**

| # | 原则 | 依据 |
|---|---|---|
| 1 | **必须有"读取即充电"的通路** | 规则 C：没有它，分布直接归零 |
| 2 | **必须有"快→慢"的巩固通路** | 规则 D：没有它，无法"提存" |
| 3 | **判据不能用相对阈值单独判** | 规则 B：相对阈值下衰减无效 |

## 七、还有一件必须说的现实约束

**硬件不是万能的。** 文献里的限制：

| 限制 | 数值/说明 |
|---|---|
| **精度** | 有效精度约 **5–7 bit/单元**（噪声限制，SNR ∝ √N） |
| **互连压降** | 大阵列时成为主要误差源，线电导需随 N **平方增长** |
| **器件漂移** | 85°C/15h 变化 < 0.8%，需**半年校准一次** |
| **模拟温度敏感性** | 必须用差分结构 |

**→ 模拟计算能到"瞬间"，但精度只有 5–7 bit，且大阵列时互连会吃掉精度。**

**这和"不遗忘"的 2 GB 存储方案是两条完全不同的路线**：
- **数字**：精确、便宜、可索引，但计算是 O(N)
- **模拟**：瞬间、省电，但精度低、难扩展

**我的判断（供你参考，不替你定）：现在阶段数字方案够用，模拟化是"如果要做成真实产品且要求实时"的下一步。**
