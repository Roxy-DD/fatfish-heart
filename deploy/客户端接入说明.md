# 另一台电脑接入 itsaplan（一键脚本）

> 用途：在**局域网内另一台 Windows 电脑**上，一键配好 hosts + 导入根证书，
> 然后用浏览器访问 `https://itsaplan.lan` 即可。
>
> 需要管理员权限（改 hosts + 装根证书）。

---

## 方法一：一键脚本（推荐）

### 1. 把这几个文件拷到另一台电脑

从主机 `C:\Users\xuee\Desktop\肥鱼之心\deploy\` 拷这两个文件到另一台电脑任意目录：

| 文件 | 作用 |
|---|---|
| `caddy\caddy-root.crt` | Caddy 根证书（让浏览器信任自签 HTTPS）|
| `setup-client.cmd` | 一键配置脚本（见下方内容）|

### 2. 右键 `setup-client.cmd` → 以管理员身份运行

### 3. 浏览器打开 `https://itsaplan.lan`

---

## 方法二：手动三步

### 第 1 步：加 hosts（管理员）

用记事本以管理员身份打开：
```
C:\Windows\System32\drivers\etc\hosts
```
末尾加一行（**IP 换成主机当前局域网 IP**）：
```
172.20.10.5  itsaplan.lan
```

怎么查主机当前 IP：在主机上运行
```powershell
Get-NetIPConfiguration -InterfaceAlias WLAN | Select-Object -ExpandProperty IPv4Address
```

### 第 2 步：导入根证书（管理员 PowerShell）

```powershell
certutil -addstore -f "ROOT" "caddy-root.crt"
```

### 第 3 步：浏览器访问

```
https://itsaplan.lan
```

用原来的账号密码登录（数据和任务都已恢复）。

## 常见问题

**Q：打不开，提示 DNS 错误？**
hosts 没配对。确认 IP 是主机当前 IP，且 hosts 里没有其他 `itsaplan.lan` 冲突行。

**Q：提示证书不受信任？**
根证书没导入。用方法二的第 2 步，或双击 `caddy-root.crt` → 安装证书 →
"本地计算机" → "受信任的根证书颁发机构"。

**Q：主机 IP 变了怎么办？**
在主机上查新 IP，改另一台电脑的 hosts 那一行即可。
或者：在主机上改成固定 IP（推荐，一劳永逸）。

**Q：浏览器仍报 ERR_CERT_AUTHORITY_INVALID？**
1. 确认导入的是 `caddy-root.crt`（不是 `intermediate.crt`）
2. 导入到"受信任的根证书颁发机构"，不是"个人"
3. 完全关闭浏览器再打开（Chrome/Edge 会缓存证书状态）

**Q：能不用域名、直接用 IP 吗？**
**不行**。Windows 的 TLS 栈（schannel）不支持对纯 IP 发 SNI，
Caddy 无法匹配证书 → 必然报 TLS 错误。必须用域名。
